# 收藏原画布与更新

别人分享的画布可以通过“我的画布 → 收藏分享画布”粘贴链接加入，也可在 `/share/:token` 页面点击“加入我的画布”。收藏保存账号与分享引用，不创建自己的副本，不保存明文分享密码。收藏页面固定只读；可编辑分享仍从原分享地址使用。

卡片与打开的只读共享画布每5秒读取作者已经保存的版本，包含最新标题、缩略图和内容。它不是未保存笔画的实时协作。暂时网络异常会显示重试状态；作者撤销、分享过期、更改密码或作者账号删除后，旧内容及可撤销历史被清空，卡片不显示旧标题或缩略图。移除收藏只移除本人的引用，原画布保留。受保护分享需重新验证新密码才能恢复引用。

编辑共享画布遇到远端更新时保留本地操作、暂停自动保存，并提示“加载最新版本”；有未保存变化时确认后再加载。保存时附带加载版本 `expectedUpdatedAt`，服务器在写锁内校验，冲突返回409并保留原作者版本，页面保留当前修改。画布规范化后的快照用作保存基准，打开无修改不会触发自动保存。旧API不带版本条件的调用保持兼容；轮询和版本检查不提供多人编辑内容合并。

接口均要求有效登录、同源请求，返回 `Cache-Control: no-store`：

- `GET /api/canvas/favorites`：本人引用列表；失效引用只返回ID、shareId、addedAt和状态。
- `POST /api/canvas/favorites`：`{shareId}`；密码仅接受 `X-Share-Password` 头。重复收藏幂等。
- `DELETE /api/canvas/favorites/:id`：取消本人收藏。
- `GET /api/canvas/favorites/:id/content`：每次重新校验源分享及授权指纹后读取原画布最新内容，固定view。

持久化文件为 `auth-data/canvas-favorites.json`，只保存id/userId/shareToken/grantFingerprint/createdAt。每账户最多200条，总量10000条、文件4MiB；新备份包含该文件，旧备份缺少此文件可兼容恢复。非法备份在写入前拒绝，写入失败不返回收藏成功。

验证包含HTTP权限/密码变更/撤销/过期/账号删除、并发去重、fsync失败重试及备份；浏览器验证包含收藏无复制、作者保存后的卡片和打开画布自动更新、撤销后清空以及移除收藏保留原画布。
