# 网站语音输入与 AI 助手

登录后，工作台和画布编辑器右下角提供「语音输入」与「AI 助手」。这些操作调用手机上的本地识别、问答和播报服务；打开网页不会自动启用麦克风。外部访问需使用 HTTPS 穿透网址，开发时可使用 localhost。

## 使用方式

1. 点击问题字段、备注、画布正在编辑的文本或其他文本输入框，把光标放在需要的位置。
2. 点击「语音输入」，在浏览器中允许麦克风。界面显示正在聆听、音量与录音时间。
3. 说完点击「完成并识别」。麦克风立即关闭，结果返回后写入原光标位置；最长录音 20 秒。
4. 若原输入框已关闭、内容在识别期间发生变化或长度超限，保留识别结果供复制，避免覆盖其他编辑。

普通文本、搜索输入框、textarea 与 contenteditable 可插入文字。密码、验证码、只读与禁用字段不可语音输入。画布双击文本后出现的原生 textarea 保留焦点，鼠标点击麦克风不会提前提交并关闭它。

打开「AI 助手」后，可明确选择工作台、项目或画布作为查询范围，再输入问题或点击提问麦克风。语音问题识别完成后直接发送到问答接口，答案保留文字和来源，也可由手机 TTS 生成音频在当前浏览器播报。可关闭自动播报或随时停止。

模型只读取当前账号有权限的数据。统计回答使用已有的项目状态，模型问答读取文字摘要。小模型上下文有限，接口返回问题或摘要截断时界面会说明，不声称看完全部资料，也不分析画布图片。当前查询不会修改项目、执行系统管理操作或开启手机自身的麦克风。长答案保留完整文字，播报使用后端生成的最多 120 字短答。

## 生命周期与数据边界

- 用户点击才申请麦克风；完成、取消、页面进入后台、切换页面与关闭浏览器会释放本次录音资源。授权期间取消后，即便麦克风随后获准也会关闭晚到的流。
- AudioWorklet 优先，旧浏览器使用 ScriptProcessor 兼容路径；源音频转换为 16 kHz、单声道、PCM16LE，最多 320000 个样本 / 640000 字节。仅保留本次录音，不保存到 localStorage、IndexedDB 或浏览器持久缓存。
- 识别结果在原字段值仍相同的情况下插入；原位置丢失时提供复制恢复。文字以原生文本事件写入 React 状态，contenteditable 只插入纯文本。
- 页面问答历史最多 6 次；切换查询范围会清空显示历史。取消会中止请求，晚到结果不会写入字段或追加到问答。
- 播报 Blob 上限 2 MiB；完成、取消、关闭面板与切换页面均撤销对象 URL。手机忙碌、语音对话抢占、超时、权限失败和网络中断都有明确状态，不自动重试可能重复的模型任务。
- HTTP 接口使用账号 cookie；识别与播放仅处理当前浏览器提交的音频和文本。匿名分享链接不获得账号语音接口权限。

## 接口

- `GET /api/voice/status`：能力、可用状态和限制。
- `POST /api/voice/transcribe`：`application/octet-stream` PCM16LE 单声道 16 kHz，返回识别文本。
- `POST /api/voice/ask`：`{ text, context: { kind: 'workspace' | 'project' | 'canvas', id? } }`，返回答案、短播报、来源和摘要截断状态。
- `POST /api/voice/speech`：`{ text }`，返回 `audio/wav`，不创建长期音频链接或缓存。

## 验证

运行 `node tests/voice-client.mjs` 检查多采样率转换、回调边界、字节序、长度限制与请求错误处理。

浏览器界面测试使用 Playwright CLI，在独立 Vite 端口 5191 启动后执行：

```powershell
npx vite --host 127.0.0.1 --port 5191 --strictPort
npx --package @playwright/cli playwright-cli -s=flowboard-voice open about:blank --browser msedge
npx --package @playwright/cli playwright-cli -s=flowboard-voice run-code --filename tests/voice-browser.js
```

浏览器测试在真实 Edge AudioContext 中生成测试音，验证真实 React 画布输入、取消、权限失败、延迟授权、问答范围、语音播放、移动布局及资源释放。接口回答为测试夹具；此测试不能代替手机模型精度、真实麦克风或真人听感验证。生产接口与手机端模型需另外实测。
