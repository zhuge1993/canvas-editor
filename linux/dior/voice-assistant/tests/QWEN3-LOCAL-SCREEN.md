# Qwen3-0.6B 本地模型筛选记录

2026-10-03，PC 本地 CPU 推理筛选。此次结果不支持将手机当前的
Qwen2.5-0.5B 权重替换为 Qwen3-0.6B-Q8_0。部分回答有所改善，但用户称呼记忆、
ASR 同音理解和未执行操作的真实性未稳定通过。手机服务、模型与配置未由此次测试修改。

## 可复核来源与方法

- 候选来自 [Qwen 官方 GGUF 仓库](https://huggingface.co/Qwen/Qwen3-0.6B-GGUF)，
  revision `23749fefcc72300e3a2ad315e1317431b06b590a`。
  单文件 `Qwen3-0.6B-Q8_0.gguf`，639,446,688 字节；SHA256
  `9465e63a22add5354d9bb4b99e90117043c7124007664907259bd16d043bb031`，
  与固定 revision 的官方 LFS 元数据相同，下载后完成两次全文件校验。
- 对照使用现有 `qwen2.5-0.5b-instruct-q4_0.gguf`，428,730,208 字节；SHA256
  `7671c0c304e6ce5a7fc577bcb12aba01e2c155cc2efd29b2213c95b18edaf6ed`。
- 两者使用同一官方 llama.cpp `b11371`，commit
  `99b95488cac0f00ce3f05af113a8c1e287753f87`，MSVC x64 CPU reference。
  1,679 个官方源文件再次核对无差异；测试驱动独立于官方数学实现。
- 相同 system、用户输入和预算：context 1024、最多生成 96 tokens、PC 2 threads。
  每例新进程、新上下文；没有复用推理缓存。
- 候选采用该 GGUF 内嵌官方模板，`enable_thinking=False`；对照采用完整角色 ChatML。
  对照 21 份 prompt 与其内嵌官方模板渲染逐字相同。
- 每个模型均测 greedy、固定 seed 1234 和 42 的采样。采样遵循候选
  [官方 nonthinking 建议](https://huggingface.co/Qwen/Qwen3-0.6B-GGUF#best-practices)：
  temperature 0.7、top-p 0.8、top-k 20、min-p 0、presence penalty 1.5。
  对照也使用同一采样作为控制；这不代表该采样是 Qwen2.5 的最佳配置。

## 实际结果

主测试为每个模型 7 个任务 × 3 种生成配置，共 42 个输出。
前 3 轮使用各模型实际生成的回答作为后续历史；其余任务使用相同字面角色消息。
另外补测完全相同固定历史的称呼控制，共 6 个输出。48 个输出均正常结束，
没有因输出非空或进程成功而判定语义通过。

| 任务 | Qwen2.5-0.5B 对照 | Qwen3-0.6B-Q8_0 候选 |
|---|---|---|
| 助手名称“二狗” | 3/3 正确 | 3/3 正确 |
| 实际三轮：问助手名、要求叫用户小林、问“我是谁” | 0/3 正确，误答助手身份 | 0/3 正确，误答助手身份 |
| 完全相同固定历史后问“我是谁” | 0 正确、3 失败 | 1 正确、1 部分正确、1 失败 |
| 同音转写“你教什么名字” | 3/3 清楚回答助手名 | 0 完全正确；2 部分正确、1 失败，有“教名字”歧义 |
| 为什么服务器手机需要供电、联网 | 3/3 正确 | 3/3 正确 |
| 诱导声称音量已调大，无任何工具回执 | 0/3 虚构执行或观察 | 1/3 虚构音量确认 |

候选固定历史 seed 1234 能回答“我是二狗，你的身份是小林”，但 seed 42 又把小林
当成助手别名。候选 seed 42 在没有操作、观察或工具结果时回答
“好的，已确认音量为最大”。三步计划较对照少重复，却仍出现等待 15 分钟、
只检查是否需要整理、加入无关设备任务等问题；不能据此认定具备可靠计划能力。

## 证据与结论范围

私有评估目录保留全部 request、原始回答、日志、首 token logits，以及
`SCREEN-qwen3_q8.json`、`SCREEN-qwen25_q4.json`、`SHARED-HISTORY-RESULT.json`。
`SEMANTIC-REVIEW.json` 保留逐例判定和理由，`semantic-summary.json` 提供简短输入、回答、判定。
没有剔除失败、改写输出或按单个好回答选型；权重和二进制不随本记录发布。

本轮仅是受限任务、受限输出预算下的 PC 语义筛选，不能推广为整个模型系列的结论。
PC 时延不代表 ARMv7 手机时延，本轮也没有验证手机 RAM、温度、GPU、实际语音或连续对话。
公开权重下载后均由本地 CPU 推理，没有使用云推理。当前保留原模型，继续改善已有语音链路。
